# Changelog

All notable changes to the Janibear project will be documented in this file.

## [1.0.0] - January 2025

### Added
- Initial release of Janibear SaaS platform
- Complete authentication system (signup, login, password reset)
- Password strength meter with real-time feedback
- Multi-tenant architecture with Row Level Security
- Organization onboarding flow
- Location management with areas/sub-areas
- Inspection template builder
- Inspection execution with scoring
- Issue tracking system
- Team/crew management
- Task assignments and completion tracking
- Scheduling system (one-time and recurring)
- Reporting and shareable links
- Bid calculator
- Contract management
- Multi-language support (English/Spanish)
- Professional marketing landing page
- Pricing page with 3 tiers
- Customer survey/quiz
- Stripe payment integration
- Toast notification system
- Loading states and skeletons
- Error boundaries
- Comprehensive documentation

### Security
- Row Level Security (RLS) on all tables
- Secure password requirements
- Organization-scoped data access
- Role-based permissions
