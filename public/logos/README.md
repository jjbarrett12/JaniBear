# Partner / company logos for the scrolling marquee

Add your logo image files here (e.g. `two-maids.png`, `abm.png`) and update the `page.tsx` array to use them:

```ts
{ src: '/logos/your-file.png', alt: 'Company Name' },
```

Use transparent PNG or SVG for best results. Recommended height ~48px; width will scale automatically.
