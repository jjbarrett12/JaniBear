# Hero images

Place these files in the `public` folder for the homepage hero:

- **scrubber.png** (or **scrubber.jpg**) – Backdrop: ride-on scrubber in a large venue. If missing, a stock image is used.
- **hero-devices.png** (or **hero-devices.jpg**) – Center: laptop and phone showing JANIBEAR. If missing, the MacBook dashboard mock is shown.

Use the exact names above so the site can find them.
