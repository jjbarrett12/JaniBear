# Deploy JaniBear

**To put your changes live on janibear.com:** Double-click **deploy-easy.bat** in this folder.

It will commit your changes, push to GitHub, and Vercel will deploy in 1–2 minutes. Your live site is **https://janibear.com**.

---

**First time?** See **LAUNCH_JANIBEAR_COM.md** to connect janibear.com to Vercel and set up DNS, Supabase, and env vars.

---

**To see changes on your PC only (no deploy):** Run `npm run dev` and open http://localhost:3001
